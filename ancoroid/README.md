# あんころいど — まだ未来ではない工場

レガシー産業を舞台に、IoT・LLM・JEV・DXをSFとして描く連載。

## 目次

1. あんころいど、工場に来る — 古い工場に一台のAndroid端末が配属される
2. 機械がしゃべった — センサーから機械の「状態」が見え始める
3. 工場の幽霊 — 深夜の異常イベントとJEV
4. LLMを呼ぶな — 観測・意味・推論・判断を分離する
5. 職人の記憶 — 消えていく暗黙知をデータとして残す
6. 紙の帳票が消えた日 — PDF化ではないDX
7. 古い機械と話す — レガシー設備と新しいAIを翻訳する
8. 工場が自分のことを説明する — Observation → State → Evidence
9. あんころいどの判断 — JEVからActionへ、人間とAIの境界
10. レガシーは死んでいない — 古い設備が未来の身体になる

## 世界観

舞台は、古い設備・紙の帳票・職人の経験で動くレガシー産業。

そこへ「あんころいど」というAndroid端末がやってくる。

あんころいどは工場を支配しない。

IoTで現実を観測し、イベントを記録し、JEVで意味と判断材料を整理し、LLMと接続する。

そして最後の判断と実行は人間に返す。

## 技術の基本構造

現実
→ IoT
→ Observation
→ Event
→ Ontology
→ JEV
→ LLM
→ Judgment
→ Action
→ Verification
→ 現実

## SFとしてのルール

「未来の技術」を発明するのではなく、
**すでに実現可能な技術を、少し未来の物語として描く。**

読者が最後に、

> 「……これ、もう作れるんじゃない？」

と思えることを目指す。
