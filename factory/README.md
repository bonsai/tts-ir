# あんこもち工場日誌

現場で起きる小さな事件から、IT・AI・データ・オントロジーを考える連載。

## 目次

1. あんこもち工場は、今日も止まらない — 現場で壊れるところをオントロジーにする
2. バーコードを読んだのに、部品がない — デジタル上の事実と現実の事実
3. Wi-Fiが切れた。でも工場は止まらない — オフラインを状態として扱う
4. あんこもんが「待っています」 — SSE・待ち行列・タイムアウト・ANR
5. ログは犯人ではない — 症状・観測・証拠・仮説・検証
6. ベテランは、なぜ機械の音だけで分かるのか — 暗黙知を観測可能な知識へ
7. 「正常」という状態は存在するのか — State Machineとして工場を見る
8. ボールはどこに落ちるべきか — AST → JEV → Action
9. 工場にLLMを呼ぶ前に — AI以前に必要な観測可能性
10. 工場そのものをJSONにしてみる — JSONは工場について話すための言葉
11. 部品が来ない — サプライチェーンと現場
12. 機械は壊れていないのに、生産が止まる — システム全体を見る
13. 同じ部品を二度登録した — 重複イベントと冪等性
14. 昨日の工場を見ている — stale dataと時間
15. あんこもち工場にセンサーが増えすぎた — データ洪水と意味
16. 工場の言葉をそろえる — Ontology / Data Dictionary / Semantic Dictionary
17. 判断と実行を分ける — JEVとAgent
18. AIに仕事を渡す — 人・機械・AIの境界
19. 工場が自分の状態を説明する — Observation → State → Evidence
20. 工場は、自分で自分を説明できるか — 現場からAgentic Factoryへ

## 基本構造

現実 → 観測 → イベント → AST → JEV → 判断 → Action → 検証 → 現実
