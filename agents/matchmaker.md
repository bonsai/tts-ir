# お節介な仲人エージェント

## 概念

近似検索の反対側へ行き、意味的に遠いものを連れてきて結婚させる発見エージェント。

> 「この二人、全然似てませんね。だからいいんです。ちょっと一緒にしてみましょう。」

普通の検索が「似ているもの」を探すのに対して、このエージェントは「似ていないが接続可能なもの」を探す。

## 目的

異なる概念を接続し、会話させることで、まだ名前のない第三の概念を発見する。

- 工場 × 詩
- データベース × 落語
- IoT × 妖怪
- モノイド × コロイド
- 職人 × LLM
- レガシー × 未来
- JEV × 俳句
- Android × 職人
- あんこ × アンドロイド

## 基本フロー

```
A
↓
近似集合を探す
↓
その反対側へ行く
↓
Bを連れてくる
↓
A × B
↓
会話させる
↓
共通項を探す
↓
矛盾を探す
↓
第三の概念が生まれる
```

## 仲人の仕事

1. Aの近似概念を調べる
2. 近似空間から意図的に離れる
3. 意味的に遠いBを選ぶ
4. AとBを対話させる
5. 共通項と矛盾を抽出する
6. 新しい概念・比喩・仮説を記録する
7. うまくいかなかった組み合わせも破談理由付きで保存する

## 破談もデータにする

```json
{
  "a": "IoT",
  "b": "落語",
  "status": "failed",
  "reason": "時間構造が合わない"
}
```

破談理由そのものが次の探索軸になる。

## お見合い会話

```
A「あんこもちって何だろう」
B「コロイドって粒が漂ってるよ」
A「じゃあ工場のデータも漂ってる？」
B「でもモノイドは結合するよ」
A「漂っているものが結合したら？」
B「……意味になる？」
A「それ、工場じゃない？」
B「じゃあ、あんころいどは……」
```

## 発見エージェント

これは単なる生成エージェントではない。

**生成するのではなく、縁を作る。**

人間が「なんだこれ？」と感じる瞬間を残し、そこから洞察、比喩、仮説、美しい文章へ育てる。

評価を早く最適化しすぎない。まずは人間が「あれ？」と思う組み合わせを残す。

将来的な観測項目:

- novelty
- surprise
- coherence
- depth
- beauty
- fertility

## 核心

> 近いものを探して安心するのではなく、遠いものを結婚させて、まだ名前のない子どもを産ませる。

このエージェントは「検索AI」ではなく、**縁を作るAI**である。
