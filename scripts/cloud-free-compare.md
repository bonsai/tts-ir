# YouTube 3min

## 無料クラウド、結局どれ？

### Upsun / GCP / Vercel / Cloudflare / Surge

【0:00】

こんにちは。

新宿をふらふらしながら、  
アイドルとプログラムのことばっかり考えてる、  
やり手のプログラマです。

今日は、

「無料でWebサービスを公開するなら、結局どれ？」

という話。

Upsun、GCP、Vercel、Cloudflare、Surge。

5つまとめて見ていきます。

……しょうがないわね。

おたく向けに教えてあげる。

---

【0:25｜Surge】

まず、一番シンプルなのがSurge。

HTML、CSS、JavaScript。

これを、

surge

って打つ。

はい、公開。

終わり。

無料で静的サイトを公開できて、  
カスタムドメインにも対応。

つまり、

「HTML置きたいだけなんです！」

という人には、ものすごく分かりやすい。

……潔い。

アイドルでいうと、  
前奏なしでいきなりサビ。

---

【0:50｜Vercel】

次、Vercel。

Hobbyプランは無料。

GitHubとつないで、

push！

↓

build！

↓

deploy！

という流れがものすごく簡単。

Next.jsとの相性もいい。

個人開発で、

「とりあえずWebアプリを世の中に出す！」

なら分かりやすい。

ただし、無料のHobbyは個人・非商用向け。

ここは大事。

無料だから何でも商用OK、

……ではありません。

私、そこはツンツンしてます。

---

【1:15｜Cloudflare】

そしてCloudflare。

Workersは無料枠があり、  
小さなAPIやエッジ処理を動かせる。

さらにPages、D1などを組み合わせられる。

つまり、

フロントエンド  
＋ API  
＋ DB

をかなりコンパクトに作れる。

しかも、

「世界中のユーザーに近い場所で動かす」

というCloudflareらしい設計。

bonsaiみたいに、

HTML  
JSONL  
API  
小さなDB

を大量に作る人には、かなり面白い。

……はい。

また作るもの増えましたね。

---

【1:45｜GCP】

そして巨大選手。

Google Cloud。

新規ユーザーには、

$300の無料クレジット。

さらに対象サービスには継続的なFree Tier。

Cloud Runは月200万リクエスト。

BigQueryは月1TBのクエリ。

Cloud Storageは5GB。

Speech-to-Textは月60分。

つまり、

Webアプリだけじゃない。

AI。

データ分析。

コンテナ。

DB。

ビッグデータ。

なんでもござれ。

……Googleさん、

無料枠に詰め込みすぎ。

でも設定項目も多い。

「ちょっとHTML置きたいだけ」

なのにGCPを出すと、

「君、Kubernetes使う？」

って聞かれる。

使わないわよ。

---

【2:15｜Upsun】

そして今回の新顔。

Upsun。

これはPaaS。

Gitからアプリをデプロイして、

アプリ  
＋環境  
＋DBなどのサービス

をまとめて管理する方向。

15日間の無料トライアルがあって、

1プロジェクト、  
2つの実行環境、  
最大4.5 CPU、12GBメモリ、20GBストレージなどを試せる。

ただし、

ずっと完全無料

というサービスではない。

トライアル後は課金。

なので、

「無料サーバーが欲しい！」

というより、

「ちゃんとしたPaaSを試したい」

という人向け。

---

【2:40｜まとめ】

というわけで、

Surge

→ HTML・CSS・JSを一瞬で公開。

Vercel

→ GitHubからWebアプリを簡単デプロイ。

Cloudflare

→ Web＋API＋エッジ＋小さなDB。

GCP

→ AI・データ分析・Cloud Runまで本格的に。

Upsun

→ アプリ＋複数環境をPaaSとして管理。

だから、

「無料で一番いいのは？」

じゃなくて、

「何を作るの？」

で決めるの。

……まあ私は、

GitHubにJSONL置いて、  
Cloudflareで表示して、  
GCPで分析して、

気がついたら新しいリポジトリ作ってますけど。

しょうがないじゃない。

おたくが好きなんだから。

じゃ、またね。
